## Conventions
- ID format: `INC-001`, `INC-002`, ... sequential, never reused.
- Status: `open`, `resolved`, `wontfix`.
- Each incident gets its own file: `doc/incidents/INC-XXX-short-slug.md`.
- Incident file must contain: root cause, resolution method, final status (resolved or not).
